# Leah Osei — GRC & Cybersecurity Portfolio

A single-page, scrollable portfolio site built around one real, publicly documented
case study: the 2015 TalkTalk data breach. Each project analyses the same incident
from a different Governance, Risk & Compliance angle.

## Live Site

Enable GitHub Pages for this repo (Settings → Pages → Deploy from branch → `main` → `/root`)
and the site will be published at `https://<your-username>.github.io/<repo-name>/`.

## Sections (scroll or use the nav)

- **Home** — intro, photo, and current goal
- **About Me** — background and skills
- **Projects** — all 3 deliverables with screenshots, download links, and a
  structured breakdown of each (goal, tools, method, results, learnings)
- **Certificates** — Tata Group and Datacom job simulations (Forage)
- **Contact** — email, LinkedIn, and CV request

## Files

```
index.html              single page containing all sections
style.css                shared styling
assets/images/           avatar photo + project screenshots
assets/files/             the 3 real downloadable deliverables
```
